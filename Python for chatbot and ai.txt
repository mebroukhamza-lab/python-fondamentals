-------------------------
1. ERROR HANDLING (try / except)
-------------------------

Programs crash. try/except lets you handle it. AI apps need this
because internet and APIs fail often.

try:
    number = int(input("Number: "))
except ValueError:
    print("That is not a number")
else:
    print("You typed", number)
finally:
    print("Always runs")

Raise your own error:

if age < 0:
    raise ValueError("Age cannot be negative")

    print(result)

=========================
AI CONCEPTS TO UNDERSTAND
=========================

Machine learning  -> computer learns patterns from data
Training          -> showing the model examples
Model             -> the result of training
Inference         -> using the model to answer
LLM               -> Large Language Model (predicts the next words)
Token             -> a piece of text (about 3/4 of a word)
Prompt            -> the text you send to the model
System prompt     -> instructions that set the model's behavior
Context window    -> how much text the model can see at once
Temperature       -> randomness (0 = focused, 1 = creative)
Embedding         -> text turned into numbers that capture meaning
RAG               -> search your documents, give the results to the LLM
Fine-tuning       -> training an existing model more on your data
Hallucination     -> the model confidently says something false

-------------------------

Chatbot that REMEMBERS the conversation:

import anthropic
from dotenv import load_dotenv

load_dotenv()
client = anthropic.Anthropic()

history = []

while True:
    user_text = input("You: ").strip()

    if user_text.lower() in ("quit", "exit"):
        break

    history.append({"role": "user", "content": user_text})

    try:
        reply = client.messages.create(
            model="claude-sonnet-5-5",
            max_tokens=1000,
            system="You are a friendly assistant. Keep answers short.",
            messages=history,
        )
    except anthropic.APIError as e:
        print("Error:", e)
        history.pop()
        continue

    answer = reply.content[0].text
    history.append({"role": "assistant", "content": answer})
    print("Bot:", answer)

WHY it remembers: the WHOLE history list is sent every time.
The model itself has no memory between calls.

Check current model names and options in the official docs:
https://docs.claude.com

=========================
SIMPLE CHATBOT WITHOUT AI (rules)
=========================

Good for learning, uses only your folder's knowledge.

answers = {
    "hello": "Hi there!",
    "how are you": "I'm fine, thanks!",
    "bye": "Goodbye!",
}

while True:
    text = input("You: ").lower().strip()

    if text == "bye":
        print("Bot:", answers["bye"])
        break

    print("Bot:", answers.get(text, "I don't understand"))
