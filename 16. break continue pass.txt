=========================
PYTHON BREAK, CONTINUE, PASS
=========================

They change how a loop behaves.

-------------------------

break    -> STOP the loop completely

for i in range(1, 10):
    if i == 5:
        break
    print(i)

Output:
1
2
3
4

-------------------------

continue -> SKIP this round, go to the next one

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Output:
1
2
4
5

-------------------------

pass     -> do NOTHING (a placeholder)

Python does not allow an empty block.
Use pass when you want to write the code later.

for i in range(3):
    pass

if age > 18:
    pass

-------------------------

BREAK IN A WHILE LOOP

while True:
    answer = input("Continue? (yes/no): ")

    if answer == "no":
        break

print("Bye!")

-------------------------

BREAK ONLY LEAVES THE CLOSEST LOOP

for i in range(3):
    for j in range(3):
        if j == 1:
            break
        print(i, j)

Output:
0 0
1 0
2 0

=========================
COMPLETE EXAMPLE (Skip negatives)
=========================

numbers = [5, -2, 8, -1, 4]
total = 0

for n in numbers:
    if n < 0:
        continue
    total += n

print("Total:", total)

Output:
Total: 17

=========================
REMEMBER
=========================

break     -> leave the loop
continue  -> jump to the next round
pass      -> do nothing (placeholder)
