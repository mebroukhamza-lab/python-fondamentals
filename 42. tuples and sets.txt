=========================
PYTHON TUPLES AND SETS
=========================

Two more ways to store many values.

=========================
TUPLE  ( )
=========================

A tuple is like a list, but it can NOT be changed.
Use it for data that must stay the same.

point = (10, 20)
colors = ("red", "green", "blue")
single = (5,)              # one item needs a comma

-------------------------

ACCESS (same as a list)

print(colors[0])           # red
print(colors[-1])          # blue
print(len(colors))         # 3

-------------------------

CHANGE? NO!

colors[0] = "black"        # ERROR: tuples cannot be changed

-------------------------

UNPACKING

x, y = point

print(x)                   # 10
print(y)                   # 20

-------------------------

LOOP

for c in colors:
    print(c)

-------------------------

METHODS

t = (1, 2, 2, 3)

print(t.count(2))          # 2
print(t.index(3))          # 3

=========================
SET  { }
=========================

A set stores UNIQUE values.
- No duplicates
- No order (no index)

numbers = {1, 2, 3, 3, 2, 1}

print(numbers)             # {1, 2, 3}

empty_set = set()          # NOT {}  ({} is an empty dictionary)

-------------------------

REMOVE DUPLICATES FROM A LIST

names = ["Ali", "Sara", "Ali", "Hamza", "Sara"]

unique = list(set(names))

print(unique)              # ['Ali', 'Sara', 'Hamza']  (any order)

-------------------------

ADD / REMOVE

s = {1, 2, 3}

s.add(4)
s.remove(2)                # error if it does not exist
s.discard(99)              # no error if it does not exist

print(s)                   # {1, 3, 4}

-------------------------

CHECK  (very fast)

print(3 in s)              # True

-------------------------

MATH WITH SETS

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)               # {1, 2, 3, 4, 5, 6}   union (all)
print(a & b)               # {3, 4}               intersection (both)
print(a - b)               # {1, 2}               only in a
print(a ^ b)               # {1, 2, 5, 6}         not in both

=========================
COMPLETE EXAMPLE
=========================

class1 = {"Ali", "Sara", "Hamza"}
class2 = {"Sara", "Lina", "Hamza"}

print("Both classes:", class1 & class2)
print("All students:", len(class1 | class2))

Output (order may change):
Both classes: {'Sara', 'Hamza'}
All students: 4

=========================
LIST vs TUPLE vs SET
=========================

list   [ ]   ordered, can change, duplicates OK
tuple  ( )   ordered, cannot change
set    { }   no order, no duplicates

=========================
REMEMBER
=========================

Tuple  -> fixed data (coordinates, RGB colors)
Set    -> unique values, fast search
set()  -> the empty set
(5,)   -> a tuple with one item
