=========================
PYTHON super()
=========================

super() = "go to my PARENT class".

Two main uses:

1) Call the parent's constructor  (super().__init__)
2) Call a parent's method         (super().method())

=========================
1) super().__init__()
=========================

The parent already knows how to save name and age.
The child only adds what is new.

class Person:

    def __init__(self, name, age):
        self.name = name
        self.age = age

class Student(Person):

    def __init__(self, name, age, school):
        super().__init__(name, age)     # parent saves name, age
        self.school = school            # child saves school

s = Student("Hamza", 20, "MIT")

print(s.name)       # Hamza
print(s.age)        # 20
print(s.school)     # MIT

-------------------------

WITHOUT super() you would repeat the parent's code:

self.name = name
self.age = age

(and if the parent changes, you must change it twice.)

=========================
2) super().method()
=========================

Use the parent's method AND add more.

class Animal:

    def speak(self):
        print("Some sound...")

class Dog(Animal):

    def speak(self):
        super().speak()          # run the parent's version first
        print("Woof!")

Dog().speak()

Output:
Some sound...
Woof!

=========================
COMPLETE EXAMPLE
=========================

class Employee:

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def info(self):
        print(f"{self.name} earns {self.salary}")

class Manager(Employee):

    def __init__(self, name, salary, team_size):
        super().__init__(name, salary)
        self.team_size = team_size

    def info(self):
        super().info()
        print(f"Manages {self.team_size} people")

m = Manager("Sara", 5000, 8)

m.info()

Output:
Sara earns 5000
Manages 8 people

=========================
REMEMBER
=========================

super()            -> the parent class
super().__init__() -> parent constructor (do it first)
super().method()   -> parent method
Never write  self  inside super().__init__(...)
