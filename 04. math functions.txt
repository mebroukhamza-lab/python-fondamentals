=========================
PYTHON MATH
=========================

Two places to find math tools:

1) Built-in functions (always available)
2) The math module (you must import it)

=========================
BUILT-IN FUNCTIONS
=========================

print(abs(-5))          # 5      (positive value)
print(round(3.567))     # 4      (round to whole number)
print(round(3.567, 2))  # 3.57   (2 decimals)
print(max(4, 9, 2))     # 9      (biggest)
print(min(4, 9, 2))     # 2      (smallest)
print(pow(2, 3))        # 8      (same as 2 ** 3)
print(sum([1, 2, 3]))   # 6      (sum of a list)

=========================
THE MATH MODULE
=========================

First, write this at the top of your file:

import math

-------------------------

print(math.sqrt(16))        # 4.0     (square root)
print(math.ceil(4.1))       # 5       (always round UP)
print(math.floor(4.9))      # 4       (always round DOWN)
print(math.pi)              # 3.141592653589793
print(math.factorial(5))    # 120     (5 x 4 x 3 x 2 x 1)
print(math.pow(2, 3))       # 8.0     (gives a float)

-------------------------

ROUND vs CEIL vs FLOOR

x = 4.5

round(x)        # 4   (Python rounds .5 to the nearest EVEN number)
math.ceil(x)    # 5
math.floor(x)   # 4

=========================
COMPLETE EXAMPLE
=========================

import math

radius = 5

area = math.pi * radius ** 2
circumference = 2 * math.pi * radius

print("Area:", round(area, 2))
print("Circumference:", round(circumference, 2))

Output:
Area: 78.54
Circumference: 31.42

=========================
TEMPLATE
=========================

import math

result = math.function(value)

=========================
MOST USED
=========================

abs(x)           -> positive value
round(x, n)      -> round to n decimals
max(a, b)        -> biggest
min(a, b)        -> smallest
math.sqrt(x)     -> square root
math.ceil(x)     -> round up
math.floor(x)    -> round down
math.pi          -> 3.14159...

=========================
REMEMBER
=========================

import math    -> needed for sqrt, ceil, floor, pi
round()        -> built-in, no import needed
