=========================
PYTHON LOGICAL OPERATORS
=========================

These operators give a result: True or False.

=========================
COMPARISON OPERATORS
=========================

==   Equal to
!=   Not equal to
>    Greater than
<    Less than
>=   Greater or equal
<=   Less or equal

Example:

age = 20

print(age == 20)    # True
print(age != 20)    # False
print(age > 18)     # True
print(age < 18)     # False

(Careful: = puts a value in a variable, == compares two values.)

=========================
LOGICAL OPERATORS
=========================

In Python we write the WORDS (not && || !):

and   -> True only if BOTH are True
or    -> True if AT LEAST ONE is True
not   -> reverses the value

-------------------------

and

age = 20
has_id = True

print(age >= 18 and has_id)     # True

-------------------------

or

is_weekend = False
is_holiday = True

print(is_weekend or is_holiday) # True

-------------------------

not

is_raining = False

print(not is_raining)           # True

-------------------------

TRUTH TABLE

True  and True   -> True
True  and False  -> False
False and False  -> False

True  or False   -> True
False or False   -> False

not True         -> False
not False        -> True

=========================
CHAINED COMPARISON (only in Python!)
=========================

age = 25

print(18 <= age <= 30)    # True

(Same as: age >= 18 and age <= 30)

=========================
in / not in
=========================

name = "Hamza"

print("H" in name)              # True
print("z" not in name)          # False

fruits = ["apple", "banana"]

print("apple" in fruits)        # True

=========================
COMPLETE EXAMPLE
=========================

age = 22
has_ticket = True

can_enter = age >= 18 and has_ticket

print(can_enter)

Output:
True

=========================
REMEMBER
=========================

and   -> both must be True
or    -> one is enough
not   -> opposite
==    -> compare
